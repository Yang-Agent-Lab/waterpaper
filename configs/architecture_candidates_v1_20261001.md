# 历史条件生成与局部分离：设计卡及有限实验方案 v1

日期：2026-10-01。状态：PROPOSED_NOT_RUN。用户授权的本轮诊断、设计与复核已完成；本文件提出下一轮实验，不表示新模型训练已获执行授权或已启动。

## 结论与主要问题

优先检验“真实历史条件下的极端雨洪生成”，暂缓新增历史局部门控及G+S组合。保留Lu et al.的生成—真实/合成分离—预测框架；先固定下游分离架构，让生成端比较可解释。条件生成本身已有CSDI、h-Diffusion等近邻，当前定位是需证明增量的候选，不是已成立的顶刊方法。

依据：data/catalog/rainfall_generation_diagnosis_v2_summary_20261001.md。9目标共同峰位置/强度分层下，未来12h的Q粗糙度和最大一步变化中位数均低于真实高Q95窗口，连续高Q95时数均更长；历史粗糙度方向不一致。未证实普遍局部雨洪错位，也未排除优化不足、尺度和接受选择的影响。诊断比较完整保存池，不能直接归因先前下游预测低估。

## 设计依据卡G：历史条件化极端雨洪生成

| 字段 | 具体内容 |
|---|---|
| 问题证据 | 未来变化偏平、high95持续期偏长、历史起始水平偏差；这些是描述性差异，未证明条件缺失是原因。 |
| 机制假设 | 用真实训练历史作为条件，减少前后段关系不匹配；极端引导负责生成高流量后续，检验其能否补充有用变化。 |
| 目标分布 | 未来P/Q在历史H与训练极端类别E下的条件分布；H为12小时已观测P/Q，不等于完整土壤/流域状态。 |
| 改动位置 | diffusion.py的ScoreModel、diffusion_loss、sample，以及train.py的条件输入传递；保留现有扩散骨干与下游三分支。 |
| 接口与训练 | history=[B,12,2]，未来联合P/Q=[B,2,12]；沿用24h布局和已知/未知mask，仅未来位置加噪及计算score目标。历史条件经小型编码器注入去噪层；精确层配置在实现规格中确定，不默认增加Transformer。 |
| 类别引导 | 分类器同步适配“未加噪历史＋加噪未来”的训练分布；引导梯度只作用未来。不能直接照搬旧整窗加噪分类器。 |
| 合成输入与泄漏 | 历史锚点只来自train，事件平衡抽样，记录锚点ID；首轮可从已有future high95的训练历史抽取，不用validation/test历史。未来标签只用于离线训练/生成，未来P和类别均不进入预测器。 |
| 简单对照 | 原联合生成、规范条件补全、事件平衡真实极端重采样。显式条件版就是本轮普通条件生成候选，不另造一个几乎相同的对照制造差异。 |
| 预期证据 | 在匹配组成/样本数/预算后，未来形态覆盖和真实验证洪峰预测优于简单对照；复制真实历史不计为生成质量提高。 |
| 否定条件 | 与补全或真实重采样无增量；只减少多样性/复制训练未来；形态更像但真实洪峰无改善；原生成器给足相当优化后差异消失。 |

潜在后续问题是：仅用绝对高Q95标签是否偏向较长高流量过程，是否需要描述给定历史下的上涨幅度/峰位置。当前没有全池预报起点Q与涨幅分布，9对曲线含涨水、平台、退水，故本轮不把“状态相对极端引导”写成选定机制或创新；需新增具体证据后再设计。

## 设计依据卡S：历史局部偏差的选择性特征传递

状态：DEFERRED_PENDING_MECHANISM_EVIDENCE。

- 原设想：共享编码器暴露逐时表示，合成分支用局部门控汇总；保留真实/合成专属分支、重构器与预测头。只读取历史P/Q。
- 当前证据：历史粗糙度并非普遍升高，整体时滞诊断不足以证明局部错位。局部异常不是已确认的预测误差来源。
- 可检验的窄主张：仅针对历史中可观测、可定位的扰动，局部选择是否优于普通注意力与整窗权重。
- 三个结构限制：同一历史配不同未来标签时门控无法分辨哪一未来不可靠；LSTM早期污染会进入后续h_t，池化门控未必能隔离；G若直接保留实测历史，原本针对合成历史的S可能失去作用对象。
- 先行检查（不在本轮执行）：已知历史扰动、仅未来标签扰动、未扰动真实极端三组；检查可见性、幅度偏置和污染传播。人工错误定位成功不等于实际合成误差被定位。
- 简单对照：常量门控、同规模普通注意力、匹配保留量的整窗权重；避免仅“有/无门控”。
- 否定条件：只有人工尖刺有效；权重主要拒绝极端幅度；错误主要在未来标签；普通注意力即可达到同样效果。
- 当前不训练S，不运行G+S全组合。以后若转向历史—未来配对可靠性，需要另写设计卡，不能让只看历史的模块悄悄读取未来。

## 首轮有限实验：同一预测器下比较生成策略

保持中国9目标各自独立训练、原事件划分、12h历史/12h未来、1/3/6/12h评价、Q95/Q99定义。国际数据及新增地区不在本轮；不以国际效果替代中国结果。

| 系统 | 数据/生成方式 | 主要排除的替代解释 |
|---|---|---|
| R0 | 仅真实数据 | 增强是否必要 |
| R1 | 事件平衡真实极端重采样；额外批量与增强组匹配 | 更多极端曝光或更多训练次数 |
| R2 | 原整窗联合生成，保留标准严格接受规则 | 当前增强参照 |
| R3 | 在原VE扩散中使用规范已知前段补全 | 固定前段本身是否已经足够 |
| R4 | 显式训练历史条件生成G | 比采样期补全是否有额外价值 |

R3须按同噪声层对已知位置加噪再注入，并处理与VE日程相容的采样；不能每一步硬贴干净历史就称为RePaint。R3/R4尽量使用相同历史锚点及极端目标。R2不能自然绑定相同锚点，必须报告并在共同历史状态/峰强度范围做敏感性比较，不能宣称完全配对生成。

下游统一使用现有Separation真实推断路径，共享初始化和预测/重构/正交设置固定；沿用已做对照的无MMD版本作为本轮共同研究配置，明确这不是自动修改现存默认配置。R0/R1也用相同真实路径容量，禁止把单LSTM历史baseline与新三分支差异当成生成增益。所有组固定实际优化步数及真实曝光，R1的额外真实批量与合成批量对应，记录参数量和采样计算量。

首轮生成质量比较读实际送入预测训练的子集，另报完整候选池；接受量不足时保留partial_failed，不用重复真实填补而伪称生成成功。将生成规则、接受规则和下游结构分开控制。

## 五个实验块及结果解释

1. 接口与优化检查：history/mask/引导梯度范围、未来信息隔离、采样可复现；检查当前及条件生成器优化曲线与相同预算敏感性。训练不足不能被解释成架构无效。
2. 生成与历史关系：只评价生成的未来以及前后连接；新增全池Q_origin=q[11]、future_peak-Q_origin、未来范围及前期状态分层，与粗糙度/持续期一起解释。该新增诊断是下一轮计划，不虚构为本次9目标结果。
3. 下游比较：R0—R4在相同真实验证事件和发报起点的峰值/峰时对照，普通小时误差辅助。
4. 必要的简单解释：真实重采样、规范补全、原生成器相当优化；不扩张为大量骨干竞争。
5. 有信号后稳定性：只对保留方案增加种子5/11和全目标确认；S与国际迁移不作为必须模块。

## 评价、决策与预算

- 主评价：事件记录主峰的同事件/同提前量成对幅值百分比误差及峰时绝对误差，分别报告，不能以一个中位数差代替成对收益。
- 实际滚动发布起点先固定为记录中每个有12h历史和完整12h未来的时刻，不看未来值选择发布；评价时按距实测峰1/3/6/12h做事后切片，同时报告全起点window-peak结果。这是事件条件评价，不是全年预警。峰在窗口外、边界峰、恒定并列峰和缺历史分别报告。
- 开发初筛seed=2。记录逐目标方向及效应大小，不以单种子平均改善宣布支持。进一步检查seed=5/11；目标/事件数量有限，跨事件依赖未知时不伪造独立性置信区间。
- 保留规则：真实峰幅值有改善且峰时无系统性恶化，再进入多种子；若幅值/峰时取舍不清，标inconclusive，不自动采用。相对R1/R3增量不足时优先保留简单方法，方法创新主张仍未成立。
- 测试：既有test已有首轮评估历史，不能称从未看过。本轮不读test调参；正式最终结论需明确开发暴露和后续独立验证范围。
- 初始配置参照现有hidden64、batch64、lr0.001、最大100epoch/patience15；新生成网络的收敛和固定步数规格需在实现时写明。不是预定最优配置。
- 预算提议：单空闲GPU、单线程数据准备；首阶段总上限1 GPU小时，先profile再决定能完成多少目标/变体，超限为partial/budget_exhausted。旧任务秒数不作为新架构时间承诺；追加种子与扩展预算另由实际profile估计。
- 顺序：实现/针对性检查并commit → R0/R1共同参照 → R2/R3/R4匹配预算比较 → 解释并决定是否增加种子。正式启动须run_versioned，本轮未启动。
