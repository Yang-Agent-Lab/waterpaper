# 基准比较的目标、指标与诊断说明

核对日期：2026-10-15。性质：解释当前实现、记录用户后续选型要求；不修改正在运行的 f9485e4 数据、训练、选模或评分条件，不授权新增训练。指标以实际代码为准；没有保存的字段明确列为待补。

## 1. 当前预测的是什么

输入为起报时刻及之前12小时降雨P与流量Q。输出为四个嵌套未来窗口的最高流量分布：

`M_H(t) = max{Q(t+1), …, Q(t+H)}`，`H ∈ {1,3,6,12}`小时。

这是四个窗口峰的概率预测，不是第1、3、6、12小时的四个流量值，也不是12小时逐小时流量轨迹；不能从这四个数恢复精确峰时。

每个站的训练资料确定Q95、Q99（该站训练流量的95%、99%分位数）。它们是研究阈值，并非地方业务警戒线。预测中位数为点预测，5%—95%分位数为90%预测区间，`p_H = P(M_H > u | 历史P/Q)`为超阈概率。当前概率由512个固定情景估计；新原生分位数模型是逆分位数采样，外尾固定于最外分位数，不是无限尾分布。

输入仅包含历史P/Q，不包含未来实测P或气象预报。中国是主要应用评价；德国、冰岛用于外源训练与分层检查。美、日仍在配对数据准备阶段，未加入本轮。冰岛P为再分析；不能统一写成测站小时实测雨量。

## 2. 先分开选模与最终比较

- 当前每个模型按**中国select的6小时归一化CRPS**选择权重，越小越好；不会按development上的最好结果回选训练轮次或调参。
- 固定权重后，用中国calibration资料确定报警概率线，再评价中国development。最终test未访问。
- 当前主判断并列看五项：6小时Q99 Brier、事件发现、实际提前时间、连续误报段、普通场景窗口峰MAE；不将其任意拼成一个总分。
- 训练loss必须可见；只有定义相同的训练/验证loss才可画成同口径曲线。不同模型的原生训练loss不可横向直接排名。

## 3. 五项主判断

| 指标 | 精确定义与统计对象 | 单位/方向 | 当前实现 |
|---|---|---|---|
| 6小时Q99 Brier | 对有资格的起报窗口，`Y=1[M_6>Q99]`，加权平均`(p_6-Y)^2`。使用combined_first_q99，包括当前Q≤Q95的低起点与Q95<Q≤Q99的升级情景；分别定报警线，连续概率评分不依赖报警线 | 无量纲；越小越好 | summary.csv；两种当前状态亦分报 |
| 事件发现 | 每个可评价站点/来源事件在真实首次超Q99前，是否至少有一次正确报警覆盖该次超阈。报告发现数/可评价数和站点等权事件发现率；缺前驱、覆盖不足等为NOT_EVALUABLE | 个、%；越高越好 | event_risk.csv、summary.csv |
| 实际提前时间 | `真实首次超阈时刻 − 最早正确报警时刻`；只在确实发现的事件计算。比较模型时另外列共同发现事件的配对差，并显式列漏报 | 小时；同事件且误报可比时越长越好 | event_risk.csv、paired_events.csv |
| 连续误报段 | 同站点、同来源事件中，按连续1小时的错误报警合成一段；时间缺口或来源事件边界另起一段。与实际FPR一起报告 | 段；越少越好 | summary.csv |
| 普通场景窗口峰MAE | 普通场景固定为真实`M_6≤Q95`的窗口；主报其6小时`|预测中位峰−真实窗口峰|`的平均值，辅报各窗口 | m³/s和除以训练Q95后的无量纲值；越小越好 | point_metrics.csv的ordinary_future6_peak_le_Q95 |

上述“事件”是当前资料支持的站点/来源事件；同一场暴雨波及多个站点不能当多个独立风暴。外国缺原生事件身份时的时间块也不能称独立洪水事件。

低起点定义为`Q(t)≤Q95`，升级情景为`Q95<Q(t)≤Q99`。`Q(t)>Q99`已处高位，不计入“首次超Q99预警”。真实超阈使用严格`>`；Q恰等于阈值不算已经超阈。

报警线λ由calibration阴性窗口确定，目标加权FPR≤5%，2%和10%仅既有敏感性分析。报警判据为`p>λ`。FPR是实际未超阈窗口里的误报比例，不是`1−precision`；development上的实际FPR不保证恰好或低于5%。当前为事件片段，误报段不能外推为全年误报次数。

## 4. 必要补充指标

| 指标 | 定义/作用 | 当前状态 |
|---|---|---|
| CRPS（连续排序概率分数） | 衡量整条预测分布是否既准确又不过度分散。情景形式为`mean|X−y| − 0.5 mean|X−X′|`；当前Q除以站点训练Q95，结果无量纲，越小越好。最终point_metrics的CRPS覆盖所有有效起报窗口，不能与受当前状态筛选的Brier假装同一人群 | 已保存；也是当前select选模依据 |
| 90%覆盖率 | 加权比例`1[q05≤M_H≤q95]`，接近90%为目标，不是越高越好 | 已保存coverage90 |
| 90%区间宽度 | `q95−q05`；在覆盖率可接受时越窄越有用，不能靠无限放宽区间增加覆盖率 | 规格已要求，原始情景可算；**本轮score.py尚未保存独立汇总字段**，不得写成已完整交付 |
| 概率可靠性 | 按预测概率分箱，对比平均预测概率与实际超阈比例；保存各箱样本量，空箱不画成零 | reliability.csv已保存 |
| 其他窗口与Q95 | 1/3/12小时及Q95预警用于解释性能随提前量和强度变化，不替换主6小时Q99问题 | 已保存 |
| 主峰前6小时E6 | 仅有合法真实主峰前6小时起报点时，6小时窗口峰绝对误差除以训练Q95；来源/覆盖不足为NOT_EVALUABLE | 已保存补充；不是任意起报的6小时点值误差 |
| 幅度合格比例 | 同一合法主峰前6小时起报点的相对峰误差严格小于20%；等于20%不合格；模型非有限预测保留失败状态 | standard_amplitude.csv已保存 |

当前不将逐小时NSE、RMSE或精确峰时误差作为四窗口峰输出的主评分；后续如果新增逐小时轨迹输出，应另行明确目标、比较范围和评分，不给现有四个峰值伪造时间轨迹。参数量、训练耗时和推断耗时可作实施成本信息，不能替代预警收益；历史未记录的显存/延迟不能补造。

## 5. 权重、比较与结论强度

窗口指标先在站点/来源事件内部平均，再在站点内部事件等权，再站点等权：`(1/B) Σ_b (1/E_b) Σ_e (1/n_be) Σ_t z_bet`。先按各指标实际资格筛选；样本量必须随指标一起报告。原始发现事件个数与站点等权发现率同时保留，不混称同一个比例。

选模、概率、点误差、事件发现具有不同统计对象，不能只报一个n。NOT_EVALUABLE不计成漏报或零误差，模型失败亦不隐去。单种子本轮用于筛选与诊断，不认领稳定普遍优势；先看同事件成对差、普通窗口是否退步、是否只在少数站点获益，再决定后续确认实验。

## 6. 训练内诊断：记录什么、能解释什么

当前版本保留学习曲线、模块梯度/激活/非有限值、固定样本及输入临时关闭检查。用户2026-10-15要求的增强版本在独立diagnostics-v2工作树验证，**不修改当前formal源码，也不补造历史缺失日志**。

| 诊断 | 定义/用途 | 结论边界 |
|---|---|---|
| 模块梯度范数、参数范数、更新范数和相对更新 | 参数范数`||θ_before||₂`；绝对更新`||θ_after−θ_before||₂`；相对更新为两者比值。每50步记录被采样的那一次优化器更新，非50步累计。观察模块是否获得梯度、实际是否改变；零原范数记NOT_EVALUABLE，无参数/冻结模块记NOT_APPLICABLE | 不合成为没有依据的“健康分”；大小本身不证明学得好 |
| 激活方差、非有限数、裁剪情况 | 区分激活塌缩、数值失败和频繁被裁剪；必须连同模块身份、步数/样本身份记录 | 仅定位线索，不能单独解释物理机制 |
| 固定样本关闭P/关闭Q | 复用既有full/zeroP/zeroQ三次输出，分别计算H6 CRPS、Q95 Brier、Q99 Brier和中位窗口峰MAE。范围为固定fit/select探针全部起报，未按正式first-cross当前状态筛选；Brier与combined_first_q99主评分分开。MAE/CRPS除以训练Q95。`Δ=关闭输入后的分数−完整输入分数`，这些误差指标Δ>0表示关闭后变差 | 零输入可能偏离训练分布；不等同重训去模块贡献，也不自动证明因果作用 |
| 概率与结构输出诊断 | 当前原生分位数输出保留修正前分位数交叉、嵌套窗口峰单调违例；最终评分用既定排序/累积最大修正，不能只展示修正后的整齐输出 | 有限尾分位数、非负性等真实限制需保留，不能悄悄改变后处理 |
| 模型特有诊断 | 未来若采用生成/分离结构，考虑真实/合成支路梯度与输出变化、生成情景多样性、尾部覆盖、固定样本关闭支路；有门控/注意力时可看饱和或分布 | 只有实际存在的模块才记录；注意力图、特征相似度和临时关闭不代替真实预测收益 |

固定报告仍为四页：学习过程（loss可见）→预测案例→概率/预警及分层表现→模块诊断。增强只复用原探针，不增加训练组、优化步、真实预测调用或访问新数据角色；梯度日志等缺失值显示“未记录”。

## 7. 比较后如何决定改哪里

- 若不同模型普通窗口都好、快速上涨都漏报，优先竞争“历史雨洪表示/滞后没学好”与“缺少起报后新增降雨信息”，不直接堆深网络。
- 若窗口峰点误差较好但Q99 Brier差，优先检查尾部概率/分布校准，不凭整体MAE选架构。
- 若训练改善而中国select退步，优先检查拟合与跨来源负迁移，不先扩大模型。
- 若完整生成—分离方法的收益集中于合成样本、真实事件未改善，检验生成有效极端情景不足与合成偏差两种竞争解释。

选后续改进起点需同时看中国6小时目标、诊断可解释性、开源可复建和成本。最强模型不一定最适合改；也不能挑一个弱模型抬高相对收益。所有新改动应保留同骨干原模型及简单替代对照。
