# 论文固定评价指标 v1

日期：2026-10-13（Asia/Taipei）。记录编号：WP-20261013-PAPER-METRICS-V1。
状态：用户已确认指标方案；本次仅记录，不修改评分代码、不重新选模、不重算历史结果、不读取新的数据角色。

## 适用目标与优先级

中国本土洪水预测为主要应用；国际资料的价值最终由中国真实事件表现判断。当前主问题是“真实主峰前6小时起报，预测随后6小时窗口峰”，不是第6小时点值，也不是全年实时预警。真实峰定位只用于事后诊断评价，不能作为预测输入。

整体流量、洪峰幅度、风险概率分别下结论，不合成能相互抵消的总分。6小时为当前主要提前量，1/3/12小时固定补充报告；不同提前量的事件覆盖有差异时，报告数量与共同事件结果，不横向挑最好提前量。

## 主终点：六小时窗口峰幅

M6(t)=max(Q[t+1],...,Q[t+6])；不包含起报时Q[t]。在沿用资格规则的真实主峰前6小时起报点计算：

- 主指标：E6=abs(M6_hat-M6)/s_b，越低越好。s_b沿用该来源站已保存的fit-only流量尺度及其元数据，不用select/calibration/development/test重新估计，不根据困难峰改尺度。
- 每个来源事件先保留配对误差，流域内事件等权平均，再对合资格中国流域等权平均。逐流域、逐事件、逐种子结果均保留；李青店和栾川单列，不替代九流域总结果。
- 同时展示M6实测值、预测值和绝对误差，单位m³/s；相对偏差RPE=100*(M6_hat-M6)/M6，单位%。负数为低估、正数为高估。RPE不取代E6主终点；同时保留abs(RPE)，不靠有符号平均掩盖正负抵消。
- M6=0时相对误差NOT_EVALUABLE，不人为加小常数；主绝对误差仍可评价。无合法峰前6小时起报点的事件保留原因和覆盖数量，不移动起报点补齐。
- 确定性轨迹取未来6小时最大值；概率轨迹逐条取最大值后，对峰值分布取中位数。不能用逐小时中位数曲线的最大值代替峰值分布中位数。仅输出窗口峰分布的模型，直接使用该分布中位数。
- 在未来采用本协议的比较中，选模继续用select的同一E6汇总；同分选更早权重。development不选checkpoint。旧实验原选模、汇总及资格规则不追溯改写。

## 整体流量：固定NSE、RMSE、MAE

令e_i=Q_hat_i-Q_i，Q单位m³/s。

| 指标 | 公式 | 解释 |
|---|---|---|
| MAE | mean(abs(e_i)) | 平均绝对误差，m³/s，越小越好 |
| MSE | mean(e_i²) | 平方误差，(m³/s)²；保留记录与补充表，不与RMSE并列作独立主要证据 |
| RMSE | sqrt(mean(e_i²)) | 对大误差更敏感，m³/s，越小越好 |
| NSE | 1-sum(e_i²)/sum((Q_i-mean(Q))²) | 越接近1越好；0对应评价样本的观测均值基准，不是持续性基准 |

- 逐提前量h=1/3/6/12分别比较Q[t+h]；不把所有提前量混成一列，不重复拼接重叠预测轨迹制造一条“连续实测过程”。概率模型的逐点代表值统一取逐小时中位数，不能按指标改用均值择优。
- 主要汇总先计算事件内指标，再流域内事件等权、流域间等权。NSE在每个事件/提前量的同一组合法起报样本上计算，观测方差为0或样本不足2时NOT_EVALUABLE；共同资格由观测和输入规则决定，不按某个模型的胜负删除事件。
- 补充列出每流域汇集全部合法起报点计算的pooled NSE，便于读者核对；明确它与事件等权NSE不同，不能替换主汇总救结果。跨流域不直接拼接m³/s计算一个总NSE。
- 两种方法只在相同事件、相同起报点、同一提前量配对。非有限预测单列为模型失败，不静默删掉；缺测或不合资格保留真实状态与共同分母。
- 对同一直接计算组，RMSE是MSE的平方根，排名相同；先逐事件取平方根再平均的macro RMSE与macro MSE不保证排名相同，不能把宏平均MSE开根号冒充宏平均RMSE。NSE也依赖平方误差，不把三者改善写成三份独立证据。KGE仅作补充，并标明实现版本；不默认新增评价实现。

## 峰时

输出未来逐小时轨迹的方法报告同一预测窗口内峰时绝对误差（小时），并保留有符号峰时偏差；并列最大值固定取最早时刻。若改变预测窗口必须另标，不把窗口边界的最高点称为完整洪水主峰时间。

仅输出峰幅或粗时间段的模型不能假造逐小时峰时，标NOT_APPLICABLE，并如实说明不能评价的能力。峰时不取代当前峰幅主终点。

## 风险概率与提前预警

- 标签：Y_H=1[max(Q[t+1],...,Q[t+H])>u_b]，H=1/3/6/12；u_b沿用本站fit Q95及既有估计规则。Q95是研究越线阈值，不是已核实的业务灾害等级。fit Q99仅补充，正例不足如实标记。
- 概率核心指标：Brier=mean((p_H-Y_H)²)，越低越好；同时展示可靠性图、分箱样本数与正例数。六小时起报未越线(q0<=u_b)为提前发现风险的主分层，起报已越线(q0>u_b)单列；同时报告全部合法起报点，不用分层混合掩盖差异。
- 常数概率参照只能由fit按相同统计口径估计；另保留持续性流量参照。训练事件资料的频率不称为全年气候发生率。
- 报警线仅在calibration按既有规则确定，目标误报率5%，2%/10%为固定敏感性；报告留出资料上的实际误报负担，不宣称实际误报完全相同，也不在development重调报警线。
- 误报率FPR=假报警起报点/(假报警起报点+正确不报警起报点)，分母为实际未越线起报点；不能混同假报警占全部报警的比例。保留既有事件/流域加权和原始计数。
- 报告可评来源事件数、被提前发现事件数/事件发现率、首次正确预警提前时间。每个来源事件只计一次发现；未命中明确记录，不能从提前时间均值中消失后宣称全面变早。无合法阈值前起报点或首次越线时刻不完整的事件标NOT_EVALUABLE。
- 当前已越线后继续暴涨，仍参与M6幅值评价；首次越线发现率不负责评价后续升级。不能以越线概率改善声称巨大洪峰幅度问题已解决。

## 分布、健康诊断与结论

概率分布方案固定补充CRPS（评价整个预测分布的误差，越低越好）以及中央90%区间的覆盖率与宽度；只在确有对应分布输出时评价，不为确定性模型伪造区间。区间变宽而覆盖更多不等于峰幅预测更准。未实现项标pending，不能称现有代码已支持。

训练损失、梯度、非有限比例、缺失率、来源质量、训练/select曲线用于解释失败，不替代真实预测收益。训练损失形式可与评价指标不同，改变损失须另记实验条件。

种子报告逐次值和均值±样本标准差；种子不增加独立洪水数。重叠、嵌套流域、同场暴雨的依赖保留，独立性未核实不虚构置信区间。已用于选型的development继续标开发证据，最终确认使用未参与选择的留出事件；本记录不授权读取test。

历史结果如另行按本协议评分，必须建立独立新报告，保留原指标、原选模和新旧差异；不得以新主指标替换已完成实验的历史结论。
