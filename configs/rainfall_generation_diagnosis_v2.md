# RESEARCH EXECUTION SPEC — saved rain–flood diagnosis v2

Approved bounded question: do the original saved strict-accepted synthetic windows differ from same-target real train windows with future high95 in rainfall/discharge timing, shape, persistence, diversity or proximity to train records? This is descriptive diagnosis for candidate architecture design, not an efficacy experiment.

Inputs are read-only: `./data/processed/china_first_flow_v1/<target>/train.jsonl.gz`, `training_transforms.json`; original `374fdab` `./results/experiments/china_first_full_v1/artifacts/<target>/sample/{synthetic.pt,status.json}`. Include all saved accepted windows, including surplus and the two sample_failed targets. No replay, sampling, training, new downloads, validation/test reads or lower-bound projection. Real values are inverse transformed in float64; synthetic float32 inverse transformation follows the original float32 acceptance check before float64 descriptive metrics. Zero rain is a <=1e-6 mm/h descriptive label only.

Unit is a 24-hour window (past 12, future 12); real windows overlap and do not form independent events. Report real event IDs/counts and source-row union. Synthetic event origin and effective independent sample size are unknown; nearest-event assignment is resemblance, not an event identifier. Across-basin event independence is unknown.

Descriptive metrics: total P over 24h and history, initial Q, future/global Q peak; future count and longest consecutive run above training Q95; full-window Q total variation, largest one-hour step, mean absolute second difference and rise/recession roughness, normalized by train Q scale; full-window P/Q argmax lag, boundary peaks and zero-rain indicators; rainfall centroid lag only for rainy windows. Argmax takes first maximum. These short-window lags cannot establish hydrologic violation: antecedent rainfall outside window, boundary truncation, initial wetness, spatial/measurement representativeness are unavailable.

Also report Q roughness/max-step separately for history/future 12h and P roughness/rainfall separately for each half. This distinguishes descriptive historical-input and future-label mismatch; it does not diagnose whether mismatch is due to limited optimization, normalization, or missing architecture. No new binary failure labels are constructed.

Control selection: jointly stratify future Q argmax into [0–3,4–7,8–11] and peak strength into real high95-window tertiles. On shared cells, compute both sources' weighted medians using identical real-window cell proportions, and report shared-support fractions. Report all unadjusted distributions as well. Sparse cells and omitted historical state can limit this adjustment; no p-values or independent-event inference.

Distance: RMS in the fixed 48-dimensional normalized joint P/Q representation. Synthetic-to-real high95 nearest neighbor; real reference leave-event-out nearest neighbor; synthetic-to-synthetic nearest neighbor excluding self. Numerically near-copy means RMS <=1e-6 and max coordinate difference <=1e-5, not proof of memorization; exact unique counts and event assignment entropy/coverage are descriptive. Also report distance to all train windows and their labels, to avoid conditional comparison concealing nearer ordinary windows. Real cross-event overlap/dependence is not fully known.

Outputs: 9-target CSV/JSON, shared-cell metrics and per-real-event descriptors, acceptance JSON with paths/counts/transforms/version/definitions/limits and tiny recomputable input excerpt. Plot three objectively selected targets: smallest, median and largest saved accepted pool; within each plot synthetic windows closest to its future peak quartiles with their nearest real high95 window in the same cell (fallback whole high95 pool recorded). Curves are representative examples, not all-target evidence. PDF and PNG generated locally with existing matplotlib; no dependency installation. Local render is versioned separately. Only authorized filenames and unique ignored experiment directory; refuse overwrite.

Budget: CPU only, BLAS/OMP threads 1, under 10 minutes; stop with explicit partial status if necessary. Commit this spec and implementation before executing through run_versioned. Server uses detached worktree of exact commit; retain original worktrees and remote edits. Main session independently recalculates one excerpt metric and inspects key assumptions. Descriptive differences support prioritizing an experiment only, never declare innovation or forecast improvement.
