# 数据准备说明

仓库只包含公开来源与变量说明，不分发观测数组、处理后的训练集、模型权重或预测输出。

- [原有数据来源清单](catalog/data_sources.md)：来源、目标覆盖及历史获取状态；状态以实际输入为准。
- [统一数据字典](catalog/unified_data_dictionary_v1.md)：变量、时间分辨率和数据角色。

中国流域是目标应用；德国、美国、冰岛、日本等资料的用途由具体实验配置确定。广西、河南等目标地区不能因为出现在计划清单就视为已取得数据。需联系数据提供方时，先准备申请材料并由维护者确认发送。

## 目录与处理顺序

```text
data/raw/          原始资料，保留来源与原始版本
data/interim/      可重建中间结果
data/processed/    带清楚处理步骤和样本身份的模型输入
data/catalog/      公开来源和变量说明
```

先确认时间戳、时区、单位、采样频率、缺失和站点/事件身份，再按完整事件划分训练/验证/测试。归一化、阈值和生成器只使用约定的训练范围。小时流量不能用日数据插值冒充；模拟和再分析流量不能当实测真值。

## 实际加载接口

`src/pointwise_benchmark_v1/dataset.py` 加载带数据清单、样本角色与身份校验的 `fit/select` 银行，读取 `x`、`y` 等数组；模型化准备见 `src/five_country_model_data_v1/`。迁移小试的 `src/extreme_process_transfer_v1/data.py` 另有自己的数组、索引和元数据契约。不要只准备一个同名 NPZ 就跳过校验。

历史配置中引用的旧权重、数据清单和 SHA 不在公开仓库。若需复现某项历史实验，应先由维护者确认可分享的输入及其身份；修改输入条件后需按新实验记录，不能沿用原实验结论。
